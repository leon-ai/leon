# Notion

Work with your Notion workspace through Notion's official MCP server.

Add Notion from **Settings → Tools and connections**, then select **Connect**.
Sign in on Notion's website and approve the access you want to grant. If Notion
requires an OAuth application for this installation, Leon shows the application
settings needed before sign-in can begin.

## Try asking

- “Find my project notes in Notion.”
- “Summarize the tasks on this Notion page.”
- “Create a page with the meeting notes we just wrote.”

Available actions depend on the functions provided by Notion's MCP server and
your workspace permissions. Adding the catalog entry alone does not authorize
access. Existing REST integration tokens cannot authorize this MCP connection.

The Leon team maintains this integration definition. Notion operates the remote
server and its account authorization.

The bundled Notion symbol is the original SVG from Wikimedia Commons, with
transparent surroundings. Attribution and source details are in
`apps/web/public/THIRD_PARTY_NOTICES.txt` in the Leon source repository.
